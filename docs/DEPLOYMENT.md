## 1. Environment variables

Format: table with columns `Name | Required | Used by | Description | Example (fake)`.

Consistency is enforced: `pnpm check:env` fails when a key exists in `.env.example` but not in the API env schema (or vice versa). Generate `.env` (and the four secret values) with `pnpm env:init`.
